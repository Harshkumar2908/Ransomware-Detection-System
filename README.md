# Ransomware Detection System

A real-time ransomware detection and monitoring system built using Python and Flask.

## Features
- Real-time threat monitoring
- Ransomware attack simulation
- Automatic detection and logging
- File recovery system
- Interactive dashboard with graph

## How to Run
1. Run monitor:
   python monitor/file_monitor.py

2. Run server:
   python app.py

3. Open browser:
   http://127.0.0.1:5000
